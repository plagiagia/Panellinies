01 / ΘΕΩΡΙΑ

Θέμα Α.

Α1 6 μονάδες

Έστω μια συνάρτηση f ορισμένη σε ένα διάστημα Δ. Αν η f είναι συνεχής στο Δ και f′(x) = 0 για κάθε εσωτερικό σημείο x του Δ, να αποδείξετε ότι η f είναι σταθερή σε όλο το διάστημα Δ.

Α2 5 μονάδες

Να διατυπώσετε το κριτήριο παρεμβολής.

Α3 4 μονάδες

Έστω f μια συνάρτηση ορισμένη σε ένα διάστημα Δ. Τι ονομάζεται αρχική συνάρτηση ή παράγουσα της f στο Δ;

Α4 10 μονάδες

Να χαρακτηρίσετε τις προτάσεις που ακολουθούν γράφοντας στο τετράδιό σας, δίπλα στο γράμμα που αντιστοιχεί σε κάθε πρόταση, τη λέξη Σωστό, αν η πρόταση είναι σωστή, ή Λάθος, αν η πρόταση είναι λανθασμένη.

  1. Μια συνάρτηση f : ℝ → ℝ είναι «1-1», αν και μόνο αν υπάρχουν διαφορετικά σημεία της γραφικής της παράστασης με την ίδια τεταγμένη.
  2. Αν μια συνάρτηση f είναι παραγωγίσιμη σε ένα σημείο x₀ του πεδίου ορισμού της, τότε είναι και συνεχής στο σημείο αυτό.
  3. Έστω μια συνάρτηση f συνεχής σε ένα διάστημα Δ και δύο φορές παραγωγίσιμη στο εσωτερικό του Δ. Αν f″(x) > 0 για κάθε εσωτερικό σημείο x του Δ, τότε η f είναι κυρτή στο Δ.
  4. Αν η συνάρτηση g είναι παραγωγίσιμη στο x₀ και η συνάρτηση f είναι παραγωγίσιμη στο g(x₀), τότε η συνάρτηση f ∘ g είναι παραγωγίσιμη στο x₀ και ισχύει (f ∘ g)′(x₀) = f′(g(x₀)) · g′(x₀).
  5. Η συνάρτηση f(x) = σφx είναι παραγωγίσιμη στο ℝ − {x | ημx = 0} και ισχύει (σφx)′ = 1 / ημ²x.
02 / ΣΥΝΑΡΤΗΣΕΙΣ

Θέμα Β.

Δίνονται οι συναρτήσεις:

f : (1, +∞) → ℝ, με f(x) = 2 ln(x − 1)
g : [2, +∞) → ℝ, με g(x) = √(x − 2) + 1

Β1 8 μονάδες

Να προσδιορίσετε τη συνάρτηση h = f ∘ g.

Στα επόμενα ερωτήματα να θεωρήσετε ότι h(x) = ln(x − 2), x ∈ (2, +∞).

Β2 9 μονάδες

Να αποδείξετε ότι η συνάρτηση h αντιστρέφεται (μονάδες 3) και να προσδιορίσετε τη συνάρτηση h⁻¹ (μονάδες 6).

Β3 8 μονάδες

Να υπολογίσετε το όριο limx→2 [h(x) · f(x) / (x − 2)].

03 / ΜΕΛΕΤΗ ΣΥΝΑΡΤΗΣΗΣ

Θέμα Γ.

Δίνεται η συνάρτηση f : ℝ → ℝ με τύπο:

f(x) = (κx³ + μx) / (x² + 1)

με κ, μ ∈ ℝ, για την οποία ισχύουν τα ακόλουθα:

  • Η f έχει οριζόντια ασύμπτωτη στο +∞.
  • Η ευθεία y = x εφάπτεται στη γραφική παράσταση της f στην αρχή των αξόνων.

Γ1 8 μονάδες

Να αποδείξετε ότι: i) κ = 0 και ii) μ = 1.

Γ2 11 μονάδες

i) Να μελετήσετε τη συνάρτηση f ως προς τη μονοτονία και τα ακρότατα (μονάδες 6).

ii) Να αποδείξετε ότι το σύνολο τιμών της f είναι το [−1/2, 1/2] (μονάδες 3) και να βρείτε το πλήθος των ριζών της εξίσωσης f(x) = 1/2 + α², για κάθε τιμή της παραμέτρου α ∈ ℝ (μονάδες 2).

Γ3 6 μονάδες

Για ν ∈ ℕ ορίζουμε Iν = ∫01 x2ν+1 / (x² + 1) dx.

i) Να αποδείξετε ότι Iν + Iν+1 = 1 / (2ν + 2), ν ∈ ℕ.

ii) Να υπολογίσετε τα I₀, I₁ και I₂.

04 / ΑΠΟΔΕΙΞΗ

Θέμα Δ.

Έστω συνάρτηση g : ℝ → ℝ παραγωγίσιμη, με συνεχή παράγωγο, για την οποία ισχύουν:

  • 0 < g(x) < 1, για κάθε x ∈ ℝ,
  • g′(x) ≠ −1, για κάθε x ∈ ℝ.

Δ1 6 μονάδες

Να αποδείξετε ότι υπάρχει μοναδικό x₁ ∈ (−1, 0) ώστε g(x₁) + x₁ = 0.

Δίνεται επιπλέον η παραγωγίσιμη συνάρτηση, με κ ∈ ℝ:

f(x) = x²(g(x) + x), για x ∈ (−∞, 0)
f(x) = 2ημx + εφx − κx, για x ∈ [0, π/2)

Δ2 2 μονάδες

Να αποδείξετε ότι κ = 3.

Δ3 7 μονάδες

Να αποδείξετε ότι στο διάστημα [0, π/2) ισχύουν:

i) f(x) ≥ 0 (μονάδες 4) και

ii) η εξίσωση 3f(x) = π έχει ακριβώς μια ρίζα, x₂ (μονάδες 3).

Δ4 10 μονάδες

i) Να αποδείξετε ότι f(x) ≥ 0 στο διάστημα [x₁, 0] (μονάδες 3).

ii) Έστω Ω το χωρίο που περικλείεται από τη γραφική παράσταση της συνάρτησης f, τον άξονα x′x και τις ευθείες x = x₁ και x = f(x₂), όπου x₁ είναι ο αριθμός από το ερώτημα Δ1 και x₂ είναι η ρίζα από το ερώτημα Δ3ii. Αν ο άξονας y′y χωρίζει το Ω σε δύο ισεμβαδικά χωρία, να αποδείξετε ότι:

∫x₁0 x³g′(x) dx = x₁⁴/4 + π²/2 − 3 ln2 − 3
