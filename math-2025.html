01 / ΘΕΩΡΙΑ

Θέμα Α.

Α1 6 μονάδες

Έστω f μια συνάρτηση ορισμένη σε ένα διάστημα Δ. Αν F είναι μια παράγουσα της f στο Δ, τότε να αποδείξετε ότι:

  • όλες οι συναρτήσεις της μορφής G(x) = F(x) + c, c ∈ ℝ, είναι παράγουσες της f στο Δ και
  • κάθε άλλη παράγουσα G της f στο Δ παίρνει τη μορφή G(x) = F(x) + c, για κάποιο c ∈ ℝ.

Α2 5 μονάδες

Να διατυπώσετε το Θεώρημα Ενδιάμεσων Τιμών.

Α3 4 μονάδες

Πότε η ευθεία x = x₀ λέγεται κατακόρυφη ασύμπτωτη της γραφικής παράστασης μιας συνάρτησης f;

Α4 10 μονάδες

Να χαρακτηρίσετε τις προτάσεις που ακολουθούν γράφοντας στο τετράδιό σας, δίπλα στο γράμμα που αντιστοιχεί σε κάθε πρόταση, τη λέξη Σωστό, αν η πρόταση είναι σωστή, ή Λάθος, αν η πρόταση είναι λανθασμένη.

  1. Έστω f : A → ℝ μια συνάρτηση η οποία είναι «1-1». Το πεδίο ορισμού της αντίστροφης συνάρτησης f⁻¹ της f είναι το σύνολο τιμών της f.
  2. Αν f, g, h είναι τρεις συναρτήσεις και ορίζεται η h ∘ (g ∘ f), τότε ορίζεται και η (h ∘ g) ∘ f και ισχύει h ∘ (g ∘ f) = (h ∘ g) ∘ f.
  3. Αν ν ∈ ℕ*, ισχύει ότι limx→0⁻ 1/x2ν = −∞.
  4. Αν μια συνάρτηση είναι κυρτή σε ένα διάστημα Δ, τότε η εφαπτομένη της γραφικής παράστασης της f σε κάθε σημείο του Δ βρίσκεται «πάνω» από τη γραφική της παράσταση, με εξαίρεση το σημείο επαφής τους.
  5. Αν η συνάρτηση g είναι παραγωγίσιμη στο x₀ και η συνάρτηση f είναι παραγωγίσιμη στο g(x₀), τότε η συνάρτηση f ∘ g είναι παραγωγίσιμη στο x₀ και ισχύει (f ∘ g)′(x₀) = f′(g(x₀)) · g′(x₀).
02 / ΣΥΝΑΡΤΗΣΕΙΣ

Θέμα Β.

Δίνεται η συνάρτηση f : ℝ → ℝ με f(x) = x³ + αx² + 9x − 3, όπου α ∈ ℝ. Δίνεται ακόμα ότι η συνάρτηση f παρουσιάζει τοπικό ακρότατο στο σημείο x₀ = 1.

Β1 5 μονάδες

Να βρείτε την τιμή του α.

Στα ερωτήματα Β2 έως Β4 να θεωρήσετε ότι α = −6.

Β2 10 μονάδες

Να αποδείξετε ότι η εξίσωση f(x) = 0 έχει τρεις θετικές πραγματικές ρίζες.

Β3 6 μονάδες

Να μελετήσετε τη συνάρτηση f ως προς την κυρτότητα και τα σημεία καμπής.

Β4 4 μονάδες

Έστω g(x) = x + f(x), x ∈ ℝ. Αν ξ ∈ ℝ, να αποδείξετε ότι οι εφαπτόμενες των γραφικών παραστάσεων των συναρτήσεων f και g στα σημεία A(ξ, f(ξ)) και B(ξ, g(ξ)), αντίστοιχα, τέμνονται πάνω στον άξονα y′y.

03 / ΜΕΛΕΤΗ ΣΥΝΑΡΤΗΣΗΣ

Θέμα Γ.

Δίνεται η συνάρτηση:

f(x) = exημx, για x < 0
f(x) = x² + x, για x ≥ 0

Γ1 6 μονάδες

Να αποδείξετε ότι η συνάρτηση f είναι συνεχής στο x₀ = 0 (μονάδες 2) αλλά όχι παραγωγίσιμη στο x₀ (μονάδες 4).

Γ2 7 μονάδες

Να βρείτε τις ασύμπτωτες της γραφικής παράστασης της συνάρτησης f.

Γ3 5 μονάδες

Να αποδείξετε ότι η γραφική παράσταση της συνάρτησης f τέμνει την ευθεία (ε): y = x + 1/2 σε ένα τουλάχιστον σημείο με τετμημένη ξ ∈ (−π, 0).

Γ4 7 μονάδες

Ένα κινητό Μ ξεκινά από την αρχή των αξόνων και κινείται κατά μήκος της καμπύλης y = f(x), x ≥ 0, ώστε ο ρυθμός μεταβολής της τετμημένης x του Μ, x′(t), να είναι θετικός για κάθε t ≥ 0. Να εξετάσετε εάν υπάρχει χρονική στιγμή t₀ ≥ 0 τέτοια ώστε ο ρυθμός μεταβολής της τεταγμένης y του Μ να είναι ίσος με τον ρυθμό μεταβολής της τετμημένης x του Μ.

04 / ΑΠΟΔΕΙΞΗ

Θέμα Δ.

Θεωρούμε μια παραγωγίσιμη συνάρτηση f : (0, +∞) → ℝ και μια παράγουσα F της f στο (0, +∞), για τις οποίες ισχύει ότι x f(x) = 2F(x)lnx, για κάθε x > 0. Δίνεται ακόμα ότι η εφαπτομένη της γραφικής παράστασης της συνάρτησης f στο σημείο M(1, f(1)) είναι παράλληλη στην ευθεία (ε): y = 2x.

Δ1 6 μονάδες

Να αποδείξετε ότι η συνάρτηση g(x) = F(x) / xlnx, x > 0, είναι σταθερή.

Δ2 9 μονάδες

i) Να υπολογίσετε το όριο limx→1 f(x)/lnx (μονάδες 4).

ii) Να αποδείξετε ότι F(1) = 1 (μονάδες 3) και F(x) = xlnx, για κάθε x > 0 (μονάδες 2).

Δ3 5 μονάδες

Να μελετήσετε ως προς τη μονοτονία τη συνάρτηση F (μονάδες 2) και να λύσετε την εξίσωση F(x²) = F(x) − (x − 1)² στο διάστημα (0, +∞) (μονάδες 3).

Δ4 5 μονάδες

Να αποδείξετε ότι για το εμβαδόν E του χωρίου που περικλείεται από τη γραφική παράσταση της συνάρτησης F, τις ευθείες x = 1, x = e και τον άξονα x′x ισχύει E > 2e − 3.
